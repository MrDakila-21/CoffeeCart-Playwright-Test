 **Coffee Cart Playwright Test**

Playwright (TypeScript) UI automation framework for https://coffee-cart.app/


**Structure**
- tests/pages/ — Page Object Model (MenuPage, CartPage, PaymentModal)
- tests/fixtures.ts — Playwright fixtures for page objects
- tests/data/ — Test data (isolated from test logic)
- tests/checkout.spec.ts — End-to-end purchase flow tests
